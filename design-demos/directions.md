## Применение скиллов

- Huashu: шесть эскизов, три самостоятельных интерактивных HTML, единые размеры, визуальный просмотр. Требуемый выбор направления пока не получен.
- Taste: одна система отступов и компонентов, равные края, собственный интерфейс вместо декоративных иллюстраций, простая предметная речь. Правила рекламных героев и полноэкранных секций не переносятся в рабочий чат.
- Emil Kowalski: отзывчивые нажатия, короткие easing-переходы, фокус, диалоги, reduced motion; никакой хореографии всей страницы.
- Impeccable: Operate, новая композиция вместо перекраски старых карточек, craft floor и честные демоданные. Context launcher initially failed executable permission; read existing docs directly. Launcher restored executable mode via sh. concept-seed succeeded, reference seed:12ecead1feb11f40, assigned third grounded candidate (messenger). This multi-skill round follows Huashu's single three-prototype selection gate, not multiple competing decision flows.

## Проверки

Полные скриншоты desktop 1440×900, mobile 390×844, staff 1440×900 в shots/. Дополнительно проверены 375, 768 и 1024 px. Варианты содержат локальные демонстрационные состояния, backend не изменён.

Huashu design_lint check/compare были вызваны, но пропустили измерения: в среде нет Python Playwright. Вместо этого выполнены проверки и просмотр через установленный Node Playwright и системный Chromium. Ledger пуст, финальный стиль не записывался до выбора пользователя.
