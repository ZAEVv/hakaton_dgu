# Визуальные референсы УПК

Проверено 6 ноября 2026. Материалы взяты только с публичных официальных страниц, скачаны и открыты для визуального просмотра. Ниже — наблюдения по изображениям и предложения для УПК, а не спецификации или точные токены этих продуктов. Исходники служат доской референсов; чужие интерфейсы, аватары и тексты в продукт не переносим.

## Telegram: мобильный диалог

Источник: [Chat Themes, Interactive Emoji, Read Receipts…](https://telegram.org/blog/chat-themes-interactive-emoji-read-receipts), 19 сентября 2021. Это исторические официальные примеры чата, не утверждение о текущем интерфейсе.

- [refs/telegram-chat-themes.jpg](refs/telegram-chat-themes.jpg) — iOS, [исходное изображение](https://telegram.org/file/464001886/2/5ugRdJYEz5c.152462/fed96846ba42463c8d).
- [refs/telegram-read-receipts.jpg](refs/telegram-read-receipts.jpg) — Android, [исходное изображение](https://telegram.org/file/464001903/2/Lg9g9LFeuuc.92807/e8ecccb14e0dc12498).

Наблюдения: три зоны — компактный заголовок, непрерывная лента, нижний ввод. Текст определяет ширину пузыря; входящие слева, исходящие справа. Сообщения одной стороны группируются теснее, смена говорящего создает паузу. Время прижато к нижнему краю пузыря. Размер основного текста заметно важнее метаданных. Аватар и навигация живут в заголовке, а не в каждой карточке. Вложения входят в ленту.

Для УПК: сохранить эту геометрию после QR, показать кабинет в одном месте заголовка, начать с короткого сообщения и компактных быстрых ответов. Поле ввода и прикрепление фото закрепить снизу. Использовать спокойный фон и различимые входящие/исходящие поверхности. Не заимствовать шумный рисунок, крупные стикеры, ложные статусы прочтения или «онлайн».

Проверка актуального контекста: [AI Summaries, New Design and More](https://telegram.org/blog/new-design-ai-summaries), 3 января 2026. [refs/telegram-ios-2026.png](refs/telegram-ios-2026.png) — кадр на 8-й секунде [официального видео](https://telegram.org/file/400780400489/3/mgjfNAD3TmE.8365548.mp4/b03a859eab60b66457). Видна плавающая стеклянная навигация. Это дополнительный контекст, не основной референс чата; такая панель не нужна для одноэкранного обращения УПК.

## Linear: рабочая очередь

Источник: [Inbox — Linear Docs](https://linear.app/docs/inbox).

- [refs/linear-inbox.png](refs/linear-inbox.png), [исходное изображение](https://webassets.linear.app/images/ornj730p/production/b442b340278740de70919c868dce1afca4335fe7-3600x2080.png).

Наблюдения: один заголовок, затем переключатель приоритетов, затем строки. У всех строк общие колонки: идентификация, основной текст с контекстом, статус и время справа. Значки небольшие и смысловые. Цвет используется точечно, основной каркас нейтрален. Основной текст ярче пояснения; размер заголовка не подавляет список. Изображение имеет рекламное затемнение краев — не копировать его в интерфейс.

Для УПК: заменить крупные обзорные карточки компактной строкой показателей и очередью. Кабинет, описание, статус и исполнитель должны сравниваться по вертикальным осям. Отобранное состояние обозначать поверхностью/контрастом, не множеством рамок. Конкретные размеры для нашего прототипа: основной текст 14–16 px, метаданные 12–13 px, достаточная высота строки для доступного нажатия.

Дополнительный источник: [Triage — Linear Docs](https://linear.app/docs/triage).

- [refs/linear-triage.png](refs/linear-triage.png), [исходное изображение](https://webassets.linear.app/images/ornj730p/production/30183e73c9ef009bb8cb14adbe97d9f34a5b9a69-2352x1632.png).

Наблюдения: список разделен тонкими горизонтальными линиями, а не отдельными карточками. Заголовок обращения сверху, источник снизу, номер и возраст справа. Для УПК полезна эта иерархия, но не мелкий текст масштабированной рекламной картинки. Приоритет и срок должны быть реальными данными; примерные обращения в дизайн-прототипах следует явно назвать демонстрационными.

## Общая опора для трех направлений

Мобильный чат наследует непрерывную ленту Telegram. Админская часть наследует сравнимые строки и иерархию Linear. Три варианта должны различаться композицией и характером типографики, а не только акцентным цветом. Название УПК, номера кабинетов и сценарии помощи дают собственную предметную идентичность.
