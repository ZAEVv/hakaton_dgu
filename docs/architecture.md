# Модели и границы доступа

| Таблица | Содержимое | Связи |
| --- | --- | --- |
| users | Имя, логин, Argon2id-хеш, роль, активность | Исполнители, авторы комментариев и истории |
| sessions | Хеш cookie, срок действия | user_id → users |
| locations | Корпус, этаж, кабинет, зона, QR-идентификатор, активность | tickets.location_id |
| categories | Название категории | tickets.category_id |
| tickets | Номер, описание, статус, приоритет, исполнитель, время, хеш tracking-токена и идемпотентность | categories, locations, users |
| comments | Текст, автор, public/internal, время | tickets, users (NULL для заявителя) |
| history | Старый/новый статус, автор, событие, время | tickets, users |
| attachments | Случайный ID, проверенное JPEG-изображение, MIME, время | tickets |
| knowledge | Вопрос, проверенный ответ, категория, источник, время | Контекст помощника |
| analyses | Тип обращения, источник ответа, время | Обезличенная статистика помощника |
| audit | Автор, действие, время | users |
| settings | Публичный адрес и серверный tracking-секрет | Системные настройки |

Пароли и tracking-токены не хранятся открытым текстом. Idempotency-key — случайный идентификатор конкретной отправки. Сервер восстанавливает tracking-токен через HMAC-SHA256 по ключу и серверному секрету и сохраняет только хеш токена.

Публичные API: справочники без qr_key, классификация, создание заявки. `/api/track/{token}` допускает доступ только к одной заявке, её публичным комментариям и вложениям. Свободного списка чужих заявок нет. Сотрудники имеют доступ ко всем заявкам после входа. Управление кабинетами, изображениями QR, пользователями, категориями и адресом доступно только admin.

История статусов всегда сохраняется. Новые заявки создаёт система. Переходы в «Назначен исполнитель»/«В работе» требуют исполнителя. «Решена»/«Отклонена» требуют публичного результата. Возврат из конечного статуса открывает заявку повторно и очищает resolved_at. Сохранение комментария к уже решённой заявке не меняет время её решения.

Защита: параметризованный SQL, проверка Origin для изменений с cookie, SameSite=Lax, HttpOnly, заголовки CSP/X-Frame-Options/nosniff/no-referrer, no-store для API, ограничение размера и формата фото, rate limit и транзакции. Клиентский JSX экранирует текст. Итоговые комментарии всегда публичны. Из публичной истории исключены события внутренних заметок.

Файлы:

- `server/app.py`: маршруты FastAPI, валидация, права, QR, статистика, вложения.
- `server/db.py`: схема, начальные записи, пароли, соединения SQLite.
- `server/ai.py`: классификация, правила безопасности, API DeepSeek и fallback.
- `server/seed.json`: системный промпт, статусы, категории, 8 инструкций.
- `src/components/Chat.jsx`: чат, черновик, создание, отслеживание.
- `src/components/Admin.jsx`: панель УПК и управление.
- `src/components/UI.jsx`, `src/styles.css`: компоненты и три палитры.


## Новые маршруты панели

- `POST /api/staff/tickets/{id}/comments` — публичное сообщение заявителю или внутренняя заметка.
- `GET /api/staff/tickets?mine=1|unassigned=1|attention=1` — быстрые фильтры очереди.
- `GET /api/staff/stats` — агрегаты для обзора и аналитики: динамика 14 дней, статусы, приоритеты, загрузка сотрудников.
- `history.visibility` — публичная история заявки не показывает внутренние события.
