# Форма заявок

Запуск из папки проекта:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r assistant/requirements.txt
cp assistant/.env.example assistant/.env
python assistant/seed.py
python assistant/main.py
```

Если `.env` уже существует, не перезаписывайте его командой `cp`.

Откройте http://127.0.0.1:5000. Форма принимает помещение, категорию, описание и необязательное фото JPEG, PNG или WebP размером до 4 МБ. Создание заявки записывается в историю. Сохраните секретную ссылку после отправки заявки. Страница отслеживания статуса и панель сотрудника ещё не реализованы.

## Форма заявки (MVP)

- Адаптивная форма с отдельным ручным выбором корпуса и помещения. JavaScript показывает помещения выбранного корпуса; без JavaScript доступны все помещения, а сервер проверяет их принадлежность корпусу.
- Корпус, помещение, категория и описание (до 5000 символов, не только пробелы) обязательны. Неверные значения сервер не сохраняет.
- **Фотографии включены в MVP.** Сервер проверяет фактический формат и декодирование JPEG/PNG/WebP, размер до 4 МБ и разрешение до 20 мегапикселей. Имя и MIME-тип от браузера не считаются доказательством формата. Файл сохраняется под случайным именем вне каталога статических файлов. Максимальный размер всего запроса — 5 МБ; оригиналы HEIC с телефона нужно преобразовать в JPEG.
- При отправке кнопка блокируется. UUID v4 запроса и уникальное ограничение в базе предотвращают повторное создание, включая одновременные запросы. Повторная отправка с тем же ключом открывает ту же заявку. Без JavaScript защита на сервере продолжает работать.
- Номер (`tickets.id`) и секретная ссылка появляются только после успешной фиксации транзакции. Ссылку можно скопировать кнопкой или вручную. Страницы не кешируются, ссылка не передаётся другим сайтам через Referer.
- При сбое записи возвращается ошибка (HTTP 503), транзакция откатывается, созданный файл удаляется. При ошибке полей или фото возвращается HTTP 400, при превышении общего размера — 413. Обычная ошибка сохраняет введённый текст и ключ запроса, но фото нужно выбрать заново; после 413 нужно вернуться к форме.

## Настройки и секреты

Приложение загружает `assistant/.env`. Переменные окружения имеют приоритет. `DATABASE` и `UPLOAD_DIR` задают пути к базе и фотографиям; относительные пути считаются от `assistant/`. `API_KEY` зарезервирован для будущей интеграции: форма пока не обращается к внешнему API. `.env.example` не содержит реальных секретов.

`TRUSTED_HOSTS` — список разрешённых доменов/IP через запятую, без схемы и порта. По умолчанию разрешены только `localhost`, `127.0.0.1`, `[::1]`: это защищает секретные ссылки от подмены заголовка Host. Для проверки на телефоне добавьте локальный IP компьютера в `.env` и после подготовки базы запустите `.venv/bin/flask --app assistant/main run --host=0.0.0.0`. Открывайте адрес компьютера с телефона в той же сети. Встроенный сервер предназначен только для разработки; публичное размещение требует production WSGI-сервера и HTTPS.

`.env`, старый `api.env`, SQLite-файлы, фотографии, виртуальное окружение и Python-кеш исключены из Git. Если ключ раньше был опубликован, удаление файла из отслеживания не удалит его из истории: отзовите ключ у провайдера и создайте новый.

## База и демонстрационные данные

`schema.sql` содержит помещения, сотрудников, заявки (номер — `id`), историю, вложения, базу знаний и секретные ссылки заявок. `python assistant/main.py` создаёт недостающие таблицы и обновляет старую базу без удаления данных.

`python assistant/seed.py` добавляет три помещения, сотрудника `demo`, три заявки с разными статусами, публичные и внутренние записи истории и два примера ответов базы знаний. Повторный запуск не дублирует эти данные и не сбрасывает пароль. Вложения появляются при загрузке фотографии через форму.

При первом создании сотрудника скрипт выводит случайный пароль один раз; сохраните его. Можно предварительно задать `DEMO_PASSWORD` в `.env`. Пароль хранится в базе только как хеш. Это демонстрационный сотрудник, интерфейс входа ещё не реализован.

У ответов базы знаний есть признак `is_verified`. Примеры не выдаются за официальные сведения колледжа и имеют значение `0`. Перед публикацией ответов ответственный сотрудник должен проверить их содержание и установить `is_verified = 1`.

```bash
.venv/bin/python -m unittest discover -s assistant -p 'test_*.py' -v
```

Тесты используют временную базу и не меняют рабочие заявки и фотографии.
